## Critical Learnings

### The defect class that dominated this work

**A measurement that fails and reads as a clean result.** Five instances, one of them inside the
check written to catch the class:

- a blast-radius grep reporting 0 callers where 2 existed (unquoted glob, zsh-only)
- a collector whose count went empty on an unmatched glob
- a reference doc's own `Check it` that could never match (em-dash encoding)
- a pipeline masking grep's exit status, so the negative branch was unreachable
- `check-guards` itself setting `FOUND=1` in a subshell — it found a real defect and printed
  `✅ no unguarded measurements`

The principle existed in four places, **none shipped or read at runtime**. Responses:
`verification-before-completion` gained a **FALSIFY** step, `plugin/scripts/check-guards`
enforces it mechanically, and the documented idiom is now **show the evidence, don't count it** —
all five instances were counts. `scripts/count` is **P5-T6** and still owed; the user asked
explicitly that it land before this effort is called complete.

### What the tracer bullet established

Phase 1 pre-registered its pass/fail conditions before running, so results could not be
retrofitted. Both halves passed. The sharpest result: **one leg explicitly cleared a finding the
other raised, and the clearance was wrong.** That forced a design correction — *"Checked and
clear" is a set of claims, not coverage* — now in `templates.md` and the verify step.

### Decisions worth not relitigating

1. **Wrap, don't rebuild.** `/code-review` fans out 8–10 finder angles and already uses
   CONFIRMED/PLAUSIBLE. wb adds named lenses and verification.
2. **Tier is the max of six axes, never LOC.** A 6-line auth diff took the top tier in the probe.
3. **`REVIEW.md` read from the base ref**, add-never-suppress — a change under review must not
   weaken its own review.
4. **Sonnet/medium for both new skills at the session level** — the cost lives in forked agents.
