# 2.1.1 baseline (P2-T8)

This record holds the numbers that the release must beat. The run is
`evals/runs/20260930T013327Z`: the tree is `4b32306` (2.1.1), with 3 repeats, the model
`sonnet`, and the stages `create_research`, `create_design`, and `create_tasks`. The report is
`evals/runs/20260930T013327Z/report.md`. Run output is gitignored, so the numbers are copied
here.

The commands were `python3 evals/run.py --before 4b32306 --repeats 3`, then
`python3 evals/report.py <run>`. The report runs `wbte_check.py` on every written document and
chat output, and `token_check.py` on every document. `token_check.py` also ran directly on each
`tasks.md`, `journal.md`, `research.md`, and `design.md`, with the same 8 failures.

## Parser-token failures

All 8 failures are missing `git_commit` and `git_branch` frontmatter keys:

- `tasks.md` in repeats 2 and 3. The 2.1.1 `create_tasks` template has neither key.
- `research.md` and `design.md` in repeat 3. The model rewrote the frontmatter and dropped the
  keys that the seed had.

No other exempt token failed. Every task ID had a digit, every journal heading ended in
`(open)` or `(closed)`, and every checkpoint had its labels and the label sentence.

## Run history

The first baseline run, `evals/runs/20260930T011540Z`, is not the baseline. In repeat 3, a
resumed `create_design` call was refused reads of its own templates, so it wrote no
`design.md`. The driver then approved the unwritten seed and ran `create_tasks` on it. Two
fixes followed, and this run used both. Every `claude` call now gets
`--add-dir <tree>/plugin`, and the driver skips `create_tasks` when `design.md` was not written.
`.claude/wb/knowledge.md` records the read refusal.

## Variance

Two runs of the same tree differ. In the P2-T6 run, the two trees were both 2.1.1, and 12.0%
and 8.4% of document sentences had more than 25 words. So compare against the 3-repeat total,
not against one repeat.
